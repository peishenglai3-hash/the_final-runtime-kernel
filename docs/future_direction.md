# Future Direction

This file preserves semantic boundaries without turning them into V1.0 modules.

## Semantics frozen, representation deferred

- Norm: a situated structure of what should or should not happen.
- Obligation: a directional commitment or duty.
- Trust: a contextual, evidence-bearing relation state; it is not assumed symmetric.
- Negotiation: a relation-changing process around conflicting goals, norms, obligations, or authority.

The next version may represent these as Relation attributes, Event sequences, Protocol variants, or new operators. V1.0 does not decide that representation. A future implementation must first show repeated, externally evidenced demand and add a new decision record.

## Other deferred directions

Independent Transfer, learned Detector or Router, complex graph models, graph databases, multiple storage backends, multi-agent relational dynamics, explicit social state, and an AGI Socialization Runtime are not hidden TODO modules. They are future hypotheses whose carriers, costs, evidence, and counterexamples remain open.
